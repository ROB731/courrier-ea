# Validation du répertoire de destinataires

Le répertoire est accessible depuis la navigation principale. Il présente une fiche d’ajout manuel pour l’entreprise, le contact, la fonction, le téléphone, la localité, l’adresse et l’e-mail, ainsi qu’une zone de recherche et une liste de gestion des fiches enregistrées.

L’assistant de campagne comprend désormais une zone « Choisir dans le répertoire ». Elle permet de rechercher, de sélectionner plusieurs fiches, puis de les injecter comme source de données de campagne avant la vérification des correspondances avec le modèle Word. Les contrôles visuels sur ordinateur confirment que cette option est lisible et cohérente avec les autres sources de données.

Le répertoire a également été contrôlé sur mobile. Le formulaire d’ajout et le résultat de recherche sont présentés en une colonne, avec une action de nouvelle campagne visible sans débordement horizontal.
